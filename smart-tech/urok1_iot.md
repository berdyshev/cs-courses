### 2. Теорія (15 хв)

#### Що таке IoT?

IoT (Internet of Things) — це мережа фізичних пристроїв, які збирають дані за допомогою датчиків, обробляють їх і передають через інтернет.

**Основні компоненти:**
- **Датчик** — читає дані (температура, вологість, рух, світло)
- **Мікроконтролер** — обробляє дані (Arduino, Raspberry Pi)
- **Wi-Fi / Bluetooth** — передає дані в мережу
- **Хмарна платформа** — зберігає й аналізує дані (Firebase, ThingSpeak)
- **Мобільний додаток** — показує результати користувачеві

#### Приклади IoT у житті

| Сфера | Приклад |
|---|---|
| **Дім** | Смарт-термостат, розумні лампи, видеодзвінок |
| **Здоров'я** | Фітнес-браслет, розумна вага, монітор серцебиття |
| **Транспорт** | Автомобіль з GPS і датчиками, велосипеди з трекерами |
| **Промисловість** | Датчики в машинах, система контролю якості |
| **Сільське господарство** | Датчики вологості грунту, опалювальні системи |

#### Як проходить робочий цикл IoT

1. Датчик вимірює температуру = 22°C
2. Мікроконтролер записує дані + час
3. Дані передаються через Wi-Fi на сервер
4. Сервер зберігає дані в базі
5. Мобільний додаток отримує дані й показує графік
6. Користувач видає команду: "вмикай опалювання"
7. Команда передається назад на пристрій
8. Пристрій виконує дію

#### Переваги та виклики

**Переваги:**
- Автоматизація рутинних процесів
- Дистанційне керування
- Аналітика (розуміння закономірностей)

**Виклики:**
- Безпека (хакери можуть перехопити дані)
- Енергоспоживання
- Сумісність між пристроями

### 3. Практична робота (20 хв)

#### Завдання: симуляція IoT-системи моніторингу температури

**Матеріали:**
- Комп'ютер з інтернетом
- Платформа ThingSpeak.com (безплатна)
- Простий скрипт на Python або Scratch

**Покроковий процес:**

**Крок 1. Реєстрація (2 хв)**
1. Зайти на https://thingspeak.com
2. Натиснути "Sign Up"
3. Придумати логін, пароль, ввести email
4. Підтвердити email

**Крок 2. Створення каналу (3 хв)**
1. Натиснути "Channels" → "My Channels"
2. Натиснути "New Channel"
3. Назва: "Моніторинг температури класу"
4. Назва поля 1: "Температура (°C)"
5. Зберегти — отримаємо Channel ID і Write API Key

**Крок 3. Відправлення даних (8 хв)**

*Варіант А — Scratch (для 9 класу):*
```
Коли натиснуто прапорець
  Повтори 5 разів
    Встановити змінну "температура" на випадкове число від 18 до 26
    Сказати "Температура: [температура]°C"
    Чекати 2 секунди
    Відправити повідомлення на ThingSpeak через блок "HTTP"
```

*Варіант Б — Python (для 10–11 класу):*
```python
import requests
import time
import random

channel_id = "YOUR_CHANNEL_ID"
api_key = "YOUR_WRITE_API_KEY"

for i in range(5):
    temp = round(random.uniform(18, 26), 1)
    url = f"https://api.thingspeak.com/update?api_key={api_key}&field1={temp}"
    response = requests.get(url)
    print(f"Температура відправлена: {temp}°C")
    time.sleep(5)
```

**Крок 4. Перегляд графіка (5 хв)**
1. Повернутися на ThingSpeak
2. Натиснути на назву каналу
3. Побачити графік у реальному часі
4. Проаналізувати: як змінювалася температура?
5. Назвати 2 причини, чому дані змінювалися

**Крок 5. Висновок (2 хв)**
- Ми щойно симулювали IoT-систему
- Датчик → мікроконтролер → інтернет → база даних → графік
- У реальності датчик вимірює справжню температуру

### 4. Підсумок (5 хв)

**Повторення ключових понять:**
1. IoT = датчики + мікроконтролер + інтернет + дані
2. Дані → обробка → зберігання → аналіз
3. Приклади: смарт-дім, здоров'я, промисловість

**Рефлексія:**
- Поверніть палець вгору, якщо зрозуміли тему
- Поверніть палець в сторону, якщо щось незрозуміло
- Поверніть палець вниз, якщо потрібна допомога
