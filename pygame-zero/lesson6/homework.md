# УРОК 6. ДОМАШНЄ ЗАВДАННЯ

Візьми гру, яку ти зробив після уроку 5, і доповни її таймером та рестартом.

---

## Завдання

Додай до своєї гри:

1. **Таймер** — відлік від 30 секунд (або більше). Коли досягає нуля — Game Over.
2. **Таймер на екрані** — видно під час гри.
3. **Рестарт клавішею R** — скидає таймер, очки, позиції персонажів. Працює лише після Game Over.

---

## ДОВІДКА

| Що | Код |
|----|-----|
| Змінна таймера | `timer = 30` |
| Показати таймер | `screen.draw.text("Час: " + str(timer), (300, 10), fontsize=30)` |
| Функція відліку | `def tick(): global timer; timer -= 1` |
| Запустити відлік | `clock.schedule_interval(tick, 1)` |
| Зупинити відлік | `clock.unschedule(tick)` |
| Подія натискання | `def on_key_down(key):` |
| Перевірка клавіші | `if key == keys.R and game_over:` |
| Червоний таймер | `color = "red" if timer < 10 else "white"` |
