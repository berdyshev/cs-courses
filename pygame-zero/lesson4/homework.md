# УРОК 4. ДОМАШНЄ ЗАВДАННЯ

Спираючись на програму з уроку 4, додай медузу — пастку, яка забирає очко при торканні і зникає в нове місце.

---

## Завдання

1. Імпортуй спрайт `sea5` з категорії **sea** у **Галереї ресурсів**
2. Створи актора `jellyfish = Actor('sea5')` і постав його на випадкову позицію
3. Намалюй медузу у `draw()`
4. Додай перевірку зіткнення у `update()`: якщо рибка торкнулась медузи — **`score -= 1`** і медуза переміщується в нове випадкове місце

**Приклад поведінки:**
```
Рибка ловить креветку → +1 очко
Рибка торкається медузи → -1 очко, медуза стрибає в нове місце
```
