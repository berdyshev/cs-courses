# УРОК 4. ЗІТКНЕННЯ ТА ОЧКИ

На цьому уроці додамо до підводної сцени здобич, яку треба ловити, і лічильник очків. Навчимося перевіряти зіткнення між спрайтами, виводити текст на екран і використовувати випадкові числа.

---

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Виведення тексту

Ми вже знаємо `screen.draw.filled_rect` і `screen.draw.filled_circle`. Третя функція того самого сімейства:

```python
screen.draw.text("Очки: " + str(score), (10, 10), fontsize=30)
#                 ^текст                  ^позиція  ^розмір шрифту
```

- `"Очки: " + str(score)` — текст для виведення; `str(score)` перетворює число на рядок
- `(10, 10)` — координати лівого верхнього кута тексту (x=10, y=10)
- `fontsize=30` — розмір шрифту у пікселях

---

### Зіткнення (colliderect)

**Зіткнення** — коли два спрайти перетнулись на екрані. Перевіряємо функцією `colliderect()`:

```python
if fish.colliderect(shrimp):
    score += 1                           # зловили!
    shrimp.x = random.randint(50, 580)   # нове випадкове місце
    shrimp.y = random.randint(50, 350)
```

---

### Точніша перевірка (distance_to)

`colliderect()` перевіряє прямокутник навколо спрайту — він часто більший за видиму фігуру. Точніша альтернатива — відстань між центрами:

```python
if fish.distance_to(shrimp) < 40:   # менше 40 пікселів — зіткнення
    score += 1
    ...
```

Число `40` підбирається на смак: менше — треба підпливти ближче, більше — зараховується здалеку.

---

### Випадкове число

```python
import random

y = random.randint(50, 360)   # ціле число від 50 до 360
```

Використаємо, щоб здобич з'являлась щоразу на іншій висоті.
