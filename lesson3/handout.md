# УРОК 3. КЕРУВАННЯ СПРАЙТОМ (KEYBOARD, МЕЖІ ЕКРАНУ)

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Як гра реагує на натиск клавіш?

Натиск на клавіші **ліворуч**, **праворуч**, **вгору**, **вниз** повинен керувати спрайтом.

У Pygame Zero це робиться через об'єкт `keyboard` у функції `update()`:

```python
def update():
    if keyboard.right:
        player.x += 5    # рухаємо праворуч на 5 пікселів
    if keyboard.left:
        player.x -= 5    # рухаємо ліворуч на 5 пікселів
    if keyboard.up:
        player.y -= 5    # рухаємо вгору на 5 пікселів
    if keyboard.down:
        player.y += 5    # рухаємо вниз на 5 пікселів
```

**Важливо:** `keyboard.right` — це **постійна перевірка**, не подія. Поки клавіша утримується — код виконується у кожному кадрі.

---

### Межі екрану — як утримати спрайт у грі

Без перевірки меж спрайт може вилетіти за край екрану. Щоб цього не було, додаємо **затискування** (clamping):

```python
def update():
    if keyboard.right:  player.x += 5
    if keyboard.left:   player.x -= 5
    if keyboard.up:     player.y -= 5
    if keyboard.down:   player.y += 5
    
    # Затискування (утримання в межах екрану)
    if player.x < 0:        player.x = 0
    if player.x > 800:      player.x = 800
    if player.y < 0:        player.y = 0
    if player.y > 600:      player.y = 600
```

Як це працює:
- Якщо **x менше 0** — встановлюємо **x = 0** (утримуємо зліва)
- Якщо **x більше 800** — встановлюємо **x = 800** (утримуємо справа)
- Те саме для y: 0 (вгору) і 600 (вниз)

Числа 800 і 600 — це `WIDTH` і `HEIGHT`, ширина й висота екрану.

---

### Читання координат

Щоб перевірити, де знаходиться спрайт:

```python
print(player.x)   # виведе поточну X-координату
print(player.y)   # виведе поточну Y-координату
print(player.pos) # виведе (x, y)
```

### Крок 2. Рух праворуч

Натисни **⏹️**, замість `pass` у `update()` напиши:

```python
    if keyboard.right:
        player.x += 5
```

Натисни **▶️**. Утримуй **стрілку вправо** — морська істота летить праворуч!

---

### Крок 3. Рух ліворуч

Натисни **⏹️**, додай у `update()` після попереднього коду:

```python

        player.x -= 5
```

Натисни **▶️**. Тепер можна рухатись **ліворуч і праворуч**.

---

### Крок 4. Рух вгору

Натисни **⏹️**, додай у `update()`:

```python
    if keyboard.up:
        player.y -= 5
```

Натисни **▶️**. Тепер можна рухатись **вгору**.

---

### Крок 5. Рух вниз

Натисни **⏹️**, додай у `update()`:

```python
    if keyboard.down:
        player.y += 5
```

Натисни **▶️**. Тепер можна рухатись у **всі чотири сторони**.

---

### Крок 6. Межа справа

Натисни **⏹️**, додай у `update()` після всіх `if keyboard...`:

```python
    if player.x > 800:
        player.x = 800
```

Натисни **▶️**. Спрайт більше не вилітає за **правий край**.

---

### Крок 7. Решта меж

Натисни **⏹️**, додай у `update()` три перевірки:

```python

        player.x = 0
    if player.y < 0:
        player.y = 0
    if player.y > 600:
        player.y = 600
```

Натисни **▶️**. Тепер спрайт **утримується в межах екрану** з усіх боків!
