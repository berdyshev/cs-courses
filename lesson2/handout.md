# УРОК 2. ACTOR: ПЕРШИЙ СПРАЙТ + АВТОМАТИЧНИЙ РУХ

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Що таке Actor?

**Actor** — це спрайт (готовий малюнок), який можна розмістити на екрані, намалювати і рухати.

На відміну від фігур (кола, прямокутника), Actor — це зображення з координатами.

---

### Де знайти спрайти?

Натисни кнопку **Галерея ресурсів** — там видно всі доступні зображення.

У коді пишеш назву зображення **без розширення**:

| У галереї | У коді |
|-----------|--------|
| `bird1.png` | `'bird1'` |
| `sea3.png` | `'sea3'` |

Доступні спрайти: `bird1`–`bird7`, `sea1`–`sea16`, `sship5`, `things15`, `things17`, `things18`

---

### Структура з Actor

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

hero = Actor('bird1')      # створюємо спрайт
hero.pos = (400, 300)      # розміщуємо в центрі екрану

def draw():
    screen.fill((173, 216, 230))
    hero.draw()             # малюємо спрайт

def update():
    hero.x += 3             # рухаємо на 3 пікселі праворуч кожен кадр

pgzrun.go()
```

**Важливо:** Actor створюється **до** функцій `draw()` і `update()`.

---

### Властивості Actor

```python
hero.pos = (400, 300)   # позиція (центр спрайту)
hero.x = 400            # тільки X
hero.y = 300            # тільки Y
hero.x += 3             # рух праворуч на 3 пікселі
hero.y -= 2             # рух вгору на 2 пікселі
hero.draw()             # малювати у draw()
```

---

### Автоматичний рух через update()

`update()` викликається **автоматично** десятки разів на секунду. Якщо змінювати координату в `update()` — спрайт рухається плавно:

```python
def update():
    hero.x += 3   # кожен кадр +3 пікселі → плавний рух
```

Більше число — швидше: `+1` повільно, `+5` середньо, `+10` швидко.

---

### Обгортання при вильоті за край

```python
def update():
    hero.x += 5
    if hero.x > 850:     # вилетів за правий край
        hero.x = -50     # з'являється з лівого краю
```

## ПРАКТИЧНЕ ЗАВДАННЯ

Будуємо сцену з **літаючою птахою** крок за кроком.  
На кожному кроці: набери новий рядок у редакторі → натисни **▶️**.

---

### Крок 1. Небо

Набери у редакторі та натисни **▶️**:

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

def draw():
    screen.fill((173, 216, 230))

def update():
    pass

pgzrun.go()
```

У вікні праворуч з'явиться блакитний екран.

---

### Крок 2. Створюємо спрайт

Натисни **⏹️**, потім додай два рядки **перед** `def draw():`:

```python
hero = Actor('bird1')
hero.pos = (400, 300)
```

Натисни **▶️**. Зовні нічого не змінилось — спрайт створено, але ще не намальовано.

---

### Крок 3. Малюємо спрайт

Натисни **⏹️**, додай у `draw()` після `screen.fill(...)`:

```python
    hero.draw()
```

Натисни **▶️**. Птаха з'явилася посередині екрану!

---

### Крок 4. Рухаємо птаху

Натисни **⏹️**, замість `pass` у `update()` напиши:

```python
    hero.x += 3
```

Натисни **▶️**. Птаха летить праворуч!

---

### Крок 5. Повертаємо птаху на початок

Натисни **⏹️**, додай у `update()` після `hero.x += 3`:

```python
    if hero.x > 850:
        hero.x = -50
```

Натисни **▶️**. Птаха вилітає праворуч і одразу з'являється ліворуч.

---

### Крок 6. Море внизу

Натисни **⏹️**, додай у `draw()` після `screen.fill(...)`:

```python
    screen.draw.filled_rect(Rect((0, 450), (800, 150)), (34, 100, 200))
```

Натисни **▶️**. Внизу з'явилось море.

---

### Крок 7. Зміни програму

1. Зміни спрайт: замість `'bird1'` спробуй `'bird3'`, `'bird5'` або `'sea3'`
2. Додай **другу птаху** — новий `Actor` з іншою висотою (`y`) і швидкістю
3. Зроби рух **вліво**: `hero.x -= 5` і обгортання зліва: `if hero.x < -50: hero.x = 850`
4. Додай сонце (коло) у `draw()` та опускай його в `update()`: `сонце.y += 1`
