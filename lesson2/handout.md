# УРОК 2. ACTOR: ПЕРШИЙ СПРАЙТ + АВТОМАТИЧНИЙ РУХ

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Що таке Actor?

**Actor** — це спрайт (готовий малюнок), який можна розмістити на екрані, намалювати і рухати. На відміну від фігур (кола, прямокутника), Actor — це зображення з координатами.

### Де знайти спрайти?

Натисни кнопку **Галерея ресурсів** — там видно всі вже додані до проєкту зображення.

Щоб додати нове зображення актора, натисни **Імпорт Зображень**, обери категорію (наприклад, **animals**, **bird**, **sea**) і додай потрібний спрайт. У зображення є назва (наприклад, `cat1`), яку і потрібно буду використовувати для створення Актора.

### Створення Actor у коді

```python
hero = Actor('cat3')                    # створюємо спрайт
hero.x = 320                            # по горизонталі — центр
hero.y = 360 - hero.height // 2        # ставимо на землю
```

**Важливо:** Actor створюється **до** функцій `draw()` і `update()`.


### Властивості Actor

```python
hero.pos = (320, 240)   # позиція (центр спрайту)
hero.x = 320            # тільки X
hero.y = 240            # тільки Y
hero.x += 3             # рух праворуч на 3 пікселі
hero.y -= 2             # рух вгору на 2 пікселі
hero.flip_x = True      # відзеркалити горизонтально
hero.scale = 2.0        # масштаб: 1.0 — звичайний, 2.0 — вдвічі більше
hero.draw()             # малювати у draw()
```


### `draw()` і `update()` — в чому різниця?

**`draw()`** — малює кадр на екрані. Викликається автоматично десятки разів на секунду. Якщо змінювати координати в `draw()` — спрайт стрибатиме, а не рухатиметься плавно. Тут можна тільки **читати** значення координат і малювати.

**`update()`** — оновлює стан гри (змінює координати, логіку) перед кожним кадром. Саме тут треба змінювати `hero.x`, щоб рух був плавним і природним.

**Чому так?** `update()` змінює стан → потім `draw()` малює оновлену картину. Результат: плавний, природний рух.

```python
def update():
    hero.x += 3   # змінюємо координату
    
def draw():
    hero.draw()   # малюємо актора на новій позиції
```

### Автоматичний рух

`update()` викликається **автоматично** десятки разів на секунду. Якщо змінювати координату в `update()` — спрайт рухається плавно:

```python
def update():
    hero.x += 3   # кожен кадр +3 пікселі → плавний рух
```

Більше число — швидше: `+1` повільно, `+5` середньо, `+10` швидко.

### Обгортання при вильоті за край

```python
def update():
    hero.x += 5
    if hero.x > 690:      # вилетів за правий край
        hero.x = -50      # з'являється з лівого краю
```
