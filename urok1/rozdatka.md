### Структура програми

```python
import pgzrun          # підключення бібліотеки — ЗАВЖДИ перший рядок

WIDTH = 800            # ширина вікна (пікселі)
HEIGHT = 600           # висота вікна (пікселі)

def draw():            # ця функція малює все на екрані
    pass

pgzrun.go()            # запуск програми — ЗАВЖДИ останній рядок
```

---

### Система координат

```
(0,0)──────────────► X
  │
  │    (300, 200)●
  │
  ▼ Y
```

- точка **(0, 0)** — лівий **верхній** кут
- **X** зростає праворуч, **Y** зростає **вниз**

---

### Кольори — формат (R, G, B)

Три числа від 0 до 255: (червоний, зелений, синій)

| Колір | RGB || Колір | RGB |
|-------|-----|-|-------|-----|
| Чорний | `(0, 0, 0)` | | Блакитний | `(173, 216, 230)` |
| Білий | `(255, 255, 255)` | | Коричневий | `(139, 69, 19)` |
| Червоний | `(255, 0, 0)` | | Помаранчевий | `(255, 165, 0)` |
| Зелений | `(0, 200, 0)` | | Жовтий | `(255, 255, 0)` |
| Синій | `(0, 0, 255)` | | Рожевий | `(100, 75, 80)` |


---

### Функції малювання

```
screen.fill( (R, G, B) )
```
Заповнює весь екран одним кольором.

```
screen.draw.filled_circle( (x, y), радіус, (R, G, B) )
                            центр
```
Малює закрашене коло. `(x, y)` — центр, далі радіус, далі колір.

```
screen.draw.filled_rect( Rect((x, y), (ширина, висота)), (R, G, B) )
                               лівий верхній кут
```
Малює закрашений прямокутник. `(x, y)` — лівий верхній кут.

### Крок 2. Сонце

Додай у `draw()` новий рядок після `screen.fill(...)`:

```python
    screen.draw.filled_circle((700, 80), 60, (255, 220, 0))
```
Коло з центром у точці x=700, y=80 та радіусом 60 жовтого кольору (255, 220, 0)

### Крок 3. Земля

```python
    screen.draw.filled_rect(Rect((0, 500), (800, 100)), (34, 139, 34))
```

Прямокутник від лівого краю (x=0), на висоті y=500, завширшки 800 (весь екран), заввишки 100.

### Крок 6. Хмара
