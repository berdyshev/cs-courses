# УРОК 4. ЗІТКНЕННЯ ТА ОЧКИ

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Що таке зіткнення?

**Зіткнення** — це коли два спрайти торкнулись один одного на екрані. Наприклад, гравець ловить рибу або мячик вдаряється у стіну.

У Pygame Zero перевіряємо зіткнення функцією `colliderect()`:

```python
if hero.colliderect(enemy):
    # зіткнення відбулось!
    pass
```

---

### Глобальні змінні

Щоб лічильник працював, потрібно дозволити функції `update()` змінювати `score`. Для цього вживаємо `global`:

```python
score = 0   # глобальна змінна (видна всім функціям)

def update():
    global score   # дозволяємо змінювати score у цій функції
    score += 1
```

Без `global score` функція не зможе змінювати змінну — тільки читати.

---

### Лічильник на екрані

Щоб вивести текст на екран, вживаємо `screen.draw.text()`:

```python
def draw():
    screen.fill((0, 0, 50))
    screen.draw.text("Очки: " + str(score), (10, 10))
```

**Важливо:** `score` — число, а `screen.draw.text()` потребує рядок. Тому перетворюємо: `str(score)`.

---

### Програма з зіткненням

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

score = 0           # глобальна змінна
hero = Actor('bird1')
hero.pos = (400, 300)

enemy = Actor('sea3')
enemy.pos = (800, 250)

def draw():
    screen.fill((0, 0, 50))
    hero.draw()
    enemy.draw()
    screen.draw.text("Очки: " + str(score), (10, 10))

def update():
    global score
    
    # рух гравця
    if keyboard.right:
        hero.x += 5
    if keyboard.left:
        hero.x -= 5
    
    # рух ворога
    enemy.x -= 3
    if enemy.x < -50:
        enemy.x = 850
    
    # перевірка зіткнення
    if hero.colliderect(enemy):
        score += 1
        enemy.x = 850

pgzrun.go()
```

## ПРАКТИЧНЕ ЗАВДАННЯ

Будуємо гру, де гравець ловить рибу, яка пливе ліворуч. Очки лічаться за кожне зіткнення.  
На кожному кроці: набери новий код у редакторі → натисни **▶️**.

---

### Крок 1. Базова програма

Набери у редакторі та натисни **▶️**:

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

score = 0
hero = Actor('bird1')
hero.pos = (400, 300)

def draw():
    screen.fill((0, 50, 100))
    hero.draw()
    screen.draw.text("Очки: " + str(score), (10, 10))

def update():
    global score
    if keyboard.right:
        hero.x += 5
    if keyboard.left:
        hero.x -= 5

pgzrun.go()
```

На екрані — птах посередині, текст "Очки: 0" у лівому куті. Гравець керує птахом стрілками вліво-вправо.

---

### Крок 2. Додаємо ворога

Натисни **⏹️**, додай два рядки після `hero.pos = (400, 300)`:

```python
enemy = Actor('sea3')
enemy.pos = (800, 250)
```

Натисни **▶️**. Зовні нічого не змінилось — ворога створено, але ще не намальовано.

---

### Крок 3. Малюємо ворога

Натисни **⏹️**, додай у `draw()` після `hero.draw()`:

```python
    enemy.draw()
```

Натисни **▶️**. З правого краю з'явилась риба!

---

### Крок 4. Рухаємо ворога

Натисни **⏹️**, додай у `update()` після керування гравцем:

```python
    enemy.x -= 3
    if enemy.x < -50:
        enemy.x = 850
```

Натисни **▶️**. Риба пливе ліворуч, потім з'являється справа.

---

### Крок 5. Перевіряємо зіткнення

Натисни **⏹️**, додай у `update()` на кінець функції:

```python
    if hero.colliderect(enemy):
        score += 1
        enemy.x = 850
```

Натисни **▶️**. Коли птах торкається риби — очки зростають на 1, риба скидується на край.

---

### Крок 6. Зміни програму

1. Зміни спрайт ворога: замість `'sea3'` спробуй `'sea5'`, `'sea10'` або `'things15'`
2. Змініть гравця: замість `'bird1'` — `'sship5'` (корабель) або інший спрайт
3. Прискорюй рибу: замість `enemy.x -= 3` напиши `enemy.x -= 5`
4. Додай **другого ворога** — новий Actor з іншою висотою й швидкістю
