# УРОК 3. КЕРУВАННЯ СПРАЙТОМ (KEYBOARD, МЕЖІ ЕКРАНУ)

На цьому уроці навчимось керувати спрайтом з клавіатури і утримувати його в межах екрану. Код пишемо і запускаємо в онлайн-редакторі: https://ed-info.github.io/pgz/

---

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Клавіатура у грі

У Pygame Zero об'єкт `keyboard` дозволяє перевіряти, яка клавіша **утримується** зараз. Перевірку робимо у функції `update()`:

```python
def update():
    if keyboard.right:   fish.x += speed
    if keyboard.left:    fish.x -= speed
    if keyboard.up:      fish.y -= speed
    if keyboard.down:    fish.y += speed
```

**Важливо:** поки клавіша **утримується** — код виконується щокадру. Це дає плавний рух.

---

### Межі екрану (clamping)

Без перевірки спрайт може вилетіти за край. Після руху перевіряємо і **затискуємо** координати:

```python
if fish.x < 0:    fish.x = 0      # лівий край
if fish.x > 640:  fish.x = 640    # правий край
if fish.y < 0:    fish.y = 0      # верхній край
if fish.y > 380:  fish.y = 380    # нижня межа (пісок)
```

Числа у межах **збігаються** з числами сцени: якщо пісок починається з `y=400` — межу ставимо `y > 380`.

### Крок 1. Підводна сцена

Натисни **Імпорт Зображень**, обери категорію **sea** і додай спрайт `sea3`. Переконайся, що він з'явився у **Галереї ресурсів**.

Набери програму і натисни **▶️**:

```python
import pgzrun

WIDTH = 640

speed = 5

fish.pos = (320, 200)

def draw():
    screen.fill("steelblue")
    screen.draw.filled_rect(Rect((0, 400), (640, 80)), "tan")
    fish.draw()

def update():
    pass

pgzrun.go()
```

На екрані: синя вода, пісочне дно, морська істота посередині. Вона не рухається.

### Крок 4. Розворот при зміні напрямку

Натисни **⏹️**. Зараз спрайт завжди дивиться праворуч. Знайди у `update()` рядки з `keyboard.right` і `keyboard.left`, і додай до кожного ще по одному рядку:

```python

        fish.x += speed
        fish.flip_x = False    # дивиться праворуч

    if keyboard.left:
        fish.x -= speed
        fish.flip_x = True     # дивиться ліворуч
```

Натисни **▶️**. Тепер істота **розвертається** при зміні напрямку!

> **Примітка:** `flip_x` працює лише в онлайн-редакторі. Якщо використовуєш інше середовище — додай до проєкту два спрайти (оригінал і дзеркальний) і перемикай через `fish.image = 'sea3_left'` / `fish.image = 'sea3_right'`.
