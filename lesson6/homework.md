# УРОК 6. ДОМАШНЄ ЗАВДАННЯ

## Завдання: Гра «Збирач»

Розробити гру, у якій:

1. **Персонаж** (Actor) керується стрілками або клавішами **WASD**
2. **Предмети для збору** (інші Actor) з'являються на екрані в випадкових місцях
3. **Система рівнів:** кожен рівень характеризується:
   - Більшою кількістю предметів на екрані одночасно
   - Швидшими предметами (якщо вони рухаються)
   - Вищою ціною за один предмет
4. **Анімація персонажа** (мінімум 2 кадри)
5. **Звук** при зборі предмета (якщо доступний)
6. **Екран Game Over** з фінальним счетом і рівнем

### Вимоги:

- **Мінімум 3 рівні**
- **Рівень підвищується** при зборі певної кількості предметів (наприклад, 10 предметів = рівень 2)
- **На екрані показано:** поточний рівень, очки, кількість зібраних предметів на цьому рівні
- **При Game Over:** показати фінальні очки, рівень і повідомлення "ГРА ЗАКІНЧЕНА"
- **Код структурований:** глобальні змінні на початку, функції чітко розділені

### Поради:

- Для випадкових координат використай `import random` і `random.randint(0, 799)`
- Предмети можуть бути статичними (Actor на екрані) або рухатися
- Спробуй комбінувати різні спрайти: `bird1`, `sea3`, `things15` для персонажа та `things17`, `things18` для предметів
- При підвищенні рівня змінюй ворога новим спрайтом або додавай другого ворога
- Звуки можуть повторюватись (`.play()` запускає звук кожен раз, коли програма викликає функцію)

### API функції
