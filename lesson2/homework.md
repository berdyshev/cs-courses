# УРОК 2. ДОМАШНЄ ЗАВДАННЯ

Створи програму з **Actor, який рухається і відбивається від меж екрану** (як м'яч).

**Завдання:**

1. Вибери спрайт: морська істота (sea1–sea16), корабель (sship5), утка (things15) або інший
2. Помісти його на екран за допомогою Actor
3. Зроби його **автоматичний рух** (update())
4. Коли Actor виходить за **праву границю**, він має **розвернутися і рухатись ліворуч**
5. Коли виходить за **ліву границю**, розвернутися і рухатись праворуч
6. Додай **фон** (sea, sky, або обидва)

**Приклад поведінки:**
```
Корабель летить праворуч... о, він на краю! 
Корабель розворотиться і летить ліворуч...
І так далі
```

**Підказка:** Замість обгортання (телепортування), змінюй напрям:

```python
speed = 5          # швидкість: додатна = праворуч, від'ємна = ліворуч

def update():
    global speed
    hero.x += speed

    if hero.x > 850:
        speed = -5   # розвертаємось ліворуч
    if hero.x < -50:
        speed = 5    # розвертаємось праворуч
```

## ДОВІДКА

| Що | Код |
|----|-----|
| Створити Actor | `hero = Actor('bird1')` |
| Встановити позицію | `hero.pos = (400, 300)` |
| Змінити X координату | `hero.x += 5` |
| Змінити Y координату | `hero.y += 5` |
| Намалювати Actor | `hero.draw()` |
| Залити екран | `screen.fill((R,G,B))` |
| Прямокутник | `screen.draw.filled_rect(Rect((x,y),(w,h)), (R,G,B))` |

**Доступні спрайти:**
- `bird1`, `bird2`, … `bird7` — птахи
- `sea1`, `sea2`, … `sea16` — морські істоти
- `sship5` — корабель
- `things15` — утка
