# УРОК 1. ПРИВІТ, PYGAME ZERO! КООРДИНАТИ І ГЕОМЕТРІЯ

На цьому уроці ми починаємо знайомитися з бібліотекою **Pygame Zero** — зручним інструментом для програмування 2D ігор на Python. Навчимося працювати з координатами на екрані та малювати простіші геометричні фігури: прямокутники, кола й лінії. Весь код писатимемо й запускатимемо в онлайн-редакторі: https://ed-info.github.io/pgz/

---

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Структура програми

```python
import pgzrun          # підключення бібліотеки — ЗАВЖДИ перший рядок

WIDTH = 800            # ширина вікна (пікселі)
HEIGHT = 600           # висота вікна (пікселі)

def draw():            # це головна функція, яка малює все на екрані
    pass

pgzrun.go()            # запуск програми — ЗАВЖДИ останній рядок
```

---

### Система координат

```
(0,0)──────────────► X
  │
  │    (300, 200)●
  │
  ▼ Y
```

- точка **(0, 0)** — лівий **верхній** кут
- **X** зростає праворуч, **Y** зростає **вниз**

---

### Кольори

Колір задається або комбінацією RGB (`(255, 0, 10)`) або за назвою — англійською, у лапках:

| Колір | Назва || Колір | Назва |
|-------|-------|-|-------|-------|
| Чорний | `"black"` | | Блакитний | `"lightblue"` |
| Білий | `"white"` | | Коричневий | `"brown"` |
| Червоний | `"red"` | | Помаранчевий | `"orange"` |
| Зелений | `"green"` | | Жовтий | `"yellow"` |
| Синій | `"blue"` | | Рожевий | `"pink"` |
| Сірий | `"gray"` | | Темно-зелений | `"darkgreen"` |


---

### Функції малювання

```
screen.fill( (R, G, B) )
screen.fill('aqua')
```
Заповнює весь екран одним кольором.

```
screen.draw.filled_circle( (x, y), радіус, 'color' )
                            центр
```
Малює закрашене коло. `(x, y)` — центр, далі радіус, далі колір.

```
screen.draw.filled_rect( Rect((x, y), (ширина, висота)), 'color' )
                               лівий верхній кут
```
Малює закрашений прямокутник. `(x, y)` — лівий верхній кут.

## ПРАКТИЧНЕ ЗАВДАННЯ

Будуємо **літній пейзаж** крок за кроком.  
На початку кожного кроку набери **лише новий рядок** і запусти програму.

---

### Крок 1. Небо

Набери програму і запусти:

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

def draw():
    screen.fill("lightblue")   # заливаємо весь екран блакитним

pgzrun.go()
```

---

### Крок 2. Сонце

Додай у `draw()` новий рядок після `screen.fill(...)`:

```python
    screen.draw.filled_circle((700, 80), 60, "yellow")
```
Коло з центром у точці x=700, y=80 та радіусом 60 жовтого кольору

---

### Крок 3. Земля

```python
    screen.draw.filled_rect(Rect((0, 500), (800, 100)), "green")
```

Прямокутник від лівого краю (x=0), на висоті y=500, завширшки 800 (весь екран), заввишки 100.

---

### Крок 4. Стовбур дерева

```python
    screen.draw.filled_rect(Rect((150, 350), (40, 150)), "brown")
```

---

### Крок 5. Крона дерева

```python
    screen.draw.filled_circle((170, 300), 90, "green")
```

Центр кола x=170 — посередині стовбура (150 + 40/2 = 170).

---

### Крок 6. Хмара

Хмара — це три кола поруч одного кольору:

```python
    screen.draw.filled_circle((300, 120), 40, "white")
    screen.draw.filled_circle((350, 100), 50, "white")
    screen.draw.filled_circle((400, 120), 40, "white")
```

---

### Крок 7. Зміни програму

1. Пересунь сонце в інший кут екрану
2. Додай друге дерево правіше від першого
3. Зміни дерево, використавши декілька кіл, для більшої крони.
4. Зміни колір неба — зроби вечірнє небо `"orange"` або нічне `"darkblue"`
