# УРОК 2. ДОМАШНЄ ЗАВДАННЯ

Створи програму з **Actor, який рухається і відбивається від меж екрану** (як м'яч).

**Завдання:**

1. Обери будь-який спрайт із середовища
2. Помісти його на екран за допомогою Actor
3. Зроби його **автоматичний рух** (update())
4. Коли Actor виходить за **праву межу**, він має **розвернутися і рухатись ліворуч**
5. Коли виходить за **ліву межу**, розвернутися і рухатись праворуч
6. При зміні напрямку руху — **відзеркалювати спрайт** (`flip_x`)
7. Додай **фон** (море, небо, або обидва)

**Приклад поведінки:**
```
Корабель рухається праворуч... о, він на краю! 
Корабель розвертається і рухається ліворуч...
І так далі
```

**Підказка:** Замість обгортання (телепортування), змінюй напрям:

```python
speed = 5          # швидкість: додатна = праворуч, від'ємна = ліворуч

def update():
    global speed
    hero.x += speed

    if hero.x > 690:
        speed = -5          # розвертаємось ліворуч
        hero.flip_x = True  # відзеркалюємо спрайт
    if hero.x < -50:
        speed = 5            # розвертаємось праворуч
        hero.flip_x = False  # повертаємо спрайт
```

## Для тих, хто впорався

**Завдання підвищеної складності: Анімація руху**

Зроби так, щоб актор **«живий» — його спрайт змінюється під час руху**, як справжня анімація.

Приклад: якщо у тебе є два зображення птиці (`bird1` і `bird2`), вони мають чергуватися, щоб мати враження, що птиця махає крильми.

**Як це зробити:**

Перед функцією `draw()` збільшуй **лічильник кадрів** кожен раз під час `update()`:

```python
frame = 0  # глобальна змінна

def update():
    global frame
    frame += 1
    # решта коду
```

Потім у `update()` перемикай зображення за формулою:

```
(frame // N) % 2
```

де `N` — число кадрів, які актор показує **одне зображення**. Менше `N` → швидша анімація, більше `N` → повільніша.

**Приклад принципу:**
- Якщо `N = 10`, то зображення змінюється кожні 10 кадрів
- Формула `(frame // 10) % 2` дає 0 або 1
- Коли 0 → показуємо `bird1`, коли 1 → показуємо `bird2`

Самостійно напишіть код, який використовує цю формулу, щоб змінювати `hero.image` між двома варіантами спрайту.
