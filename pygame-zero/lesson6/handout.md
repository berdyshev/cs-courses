# УРОК 6. РОЗШИРЕННЯ: ЗВУКИ, РІВНІ, АНІМАЦІЯ

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Звуки в Pygame Zero

Почути звук дуже просто — потрібен один рядок коду:

```python
sounds.collision.play()
```

**Як це працює:**
- У редакторі є кнопка **Галерея ресурсів** — там доступні готові звуки
- Назва звуку пишеться **без розширення** (файл `collision.wav` → код `sounds.collision`)
- Метод `.play()` запускає звук один раз

Приклад: коли персонаж торкається ворога, програма грає звук зіткнення.

---

### Анімація спрайту: циклічна змінювання зображення

Замість того, щоб малювати спрайт один раз, можна мінювати його зображення — птаха помахує крилами!

Потрібні три речі:

**1. Глобальні змінні для відстеження кадру:**

```python
frame = 1              # поточний номер кадру (1, 2, 3, ... 7)
frame_timer = 0        # лічильник часу до наступної зміни кадру
```

**2. У `update()` — збільшуємо лічильник і змінюємо кадр:**

```python
def update():
    global frame, frame_timer
    
    frame_timer += 1
    if frame_timer >= 10:       # кожні 10 кадрів програми
        frame_timer = 0
        frame += 1
        if frame > 7:           # після 7-го кадру повертаємось до 1-го
            frame = 1
        hero.image = 'bird' + str(frame)   # змінюємо зображення
```

**3. Результат:** птаха анімується (bird1 → bird2 → bird3 → ... → bird7 → bird1 → ...)

**Примітка:** значення `10` контролює швидкість анімації. Більше число — повільніше (frame_timer += 1 більше раз перш ніж змінити кадр).

---

### Рівні гри

Рівень — це показник складності. Вища рівень = вороги швидші, більше очок для підвищення.

**Глобальна змінна:**

```python
level = 1
score = 0
```

**У `update()` — перевіряємо умову підвищення рівня:**

```python
def update():
    global score, level
    
    # відстежуємо набрані очки (колізії з ворогом)
    # якщо набрали досить очок — рівень зростає
    if score >= level * 5:
        level += 1
```

**Це означає:**
- Рівень 1: потрібно 5 очок для рівня 2
- Рівень 2: потрібно 10 очок для рівня 3
- Рівень 3: потрібно 15 очок для рівня 4
- І так далі...

**Швидкість залежить від рівня:**

```python
def update():
    # основна швидкість 2 + (рівень - 1) = більш швидко на вищих рівнях
    enemy.x -= 2 + level
```

**На екрані показуємо рівень:**

```python
def draw():
    screen.draw.text("Рівень: " + str(level), (650, 10))
```

## ПРАКТИЧНЕ ЗАВДАННЯ

Будуємо повну гру з **анімованою птахою**, **рівнями** і **системою очок**.  
На кожному кроці: натисни **▶️** щоб запустити, потім **⏹️** щоб зупинити перед редагуванням.

### Крок 1. Базова гра (стартовий код)

Набери у редакторі та натисни **▶️**:

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

hero = Actor('bird1')
hero.pos = (100, 300)
hero.speed = 5

enemy = Actor('bird5')
enemy.pos = (750, 250)

score = 0
game_over = False

def draw():
    screen.fill((173, 216, 230))
    hero.draw()
    enemy.draw()
    screen.draw.text("Очки: " + str(score), (10, 10))
    if game_over:
        screen.draw.text("ГАРА СКІНЧЕНА!", (300, 300))

def update():
    global score, game_over
    
    if game_over:
        return
    
    # керування героєм
    if keyboard.up:
        hero.y -= hero.speed
    if keyboard.down:
        hero.y += hero.speed
    
    # ворог рухається ліворуч
    enemy.x -= 2
    if enemy.x < -50:
        enemy.x = 850
    
    # перевірка зіткнення
    if hero.colliderect(enemy):
        score += 1
        enemy.x = 850

pgzrun.go()
```

На екрані: птаха ліворуч, враг праворуч. Керуй стрілками **вгору/вниз**. Торкайся ворога щоб набрати очко.

### Крок 2. Готуємо змінні для анімації

Натисни **⏹️**, додай **після** глобальних змінних (після `game_over = False`):

```python
frame = 1
frame_timer = 0
```

Натисни **▶️**. Зовні нічого не змінилось — змінні готові для наступного кроку.

---

### Крок 3. Збільшуємо лічильник кадрів

Натисні **⏹️**, додай у `update()` в самий початок (другий рядок після `global score, game_over`):

```python
    global frame, frame_timer
```

Натисни **⏹️** знову, додай у `update()` після перевірки `if game_over: return`:

```python
    frame_timer += 1
    if frame_timer >= 10:
        frame_timer = 0
        frame += 1
        if frame > 7:
            frame = 1
```

Натисни **▶️**. Поведінка гри не змінилась — лічильник просто рахує кадри.

---

### Крок 4. Анімуємо птаху

Натисні **⏹️**, додай у `update()` **прямо після блоку з frame** (після `frame = 1`):

```python
        hero.image = 'bird' + str(frame)
```

Натисни **▶️**. Птаха тепер махає крилами (циклічна анімація bird1 → bird2 → ... → bird7)!

---

### Крок 5. Додаємо рівні

Натисні **⏹️**, додай **після** `game_over = False`:

```python
level = 1
```

Натисни **▶️**. Рівень 1 видно у коді, але на екрані його ще немає.

---

### Крок 6. Показуємо рівень на екрані

Натисні **⏹️**, знайди у `draw()` рядок `screen.draw.text("Очки: " + str(score), (10, 10))` і додай **після** нього:

```python
    screen.draw.text("Рівень: " + str(level), (10, 40))
```

Натисни **▶️**. Тепер вгорі ліворуч видно "Рівень: 1".

---

### Крок 7. Система підвищення рівня

Натисні **⏹️**, у `update()` знайди блок з анімацією і додай **після нього**:

```python
    if score >= level * 5:
        level += 1
```

Натисни **▶️**. Тепер при 5 очках рівень підвищується на 2, при 10 очках — на 3 і т.д.

---

### Крок 8. Швидкість залежить від рівня

Натисні **⏹️**, у `update()` знайди рядок `enemy.x -= 2` і замість нього напиши:

```python
    enemy.x -= 2 + level
```

Натисни **▶️**. На вищих рівнях ворог рухається швидше!
