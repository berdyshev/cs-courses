# УРОК 5. СТАН ГРИ ТА GAME OVER

На цьому уроці додамо до підводної гри небезпечну медузу і стан **Game Over**. Навчимося зупиняти гру і виводити підсумковий екран.

---

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Стан гри — змінна game_over

У будь-якій грі є два режими: **гра йде** і **гра закінчилась**. Ми зберігаємо це у змінній:

```python
game_over = False   # гра йде
```

Коли сталось щось погане — встановлюємо:

```python
game_over = True    # гра закінчилась
```

---

### Як зупинити логіку гри

Коли `game_over = True`, рухати персонажів не треба. Використовуємо `return` — він одразу виходить з функції:

```python
def update():
    global game_over
    if game_over:
        return          # виходимо — нічого не робимо

    # решта логіки — виконується тільки якщо гра йде
    fish.x += 5
```

---

### Екран Game Over

Те саме — у `draw()`. Якщо гра закінчилась, малюємо екран Game Over і виходимо:

```python
def draw():
    screen.fill("steelblue")

    if game_over:
        screen.draw.text("GAME OVER", (150, 200), fontsize=60, color="red")
        screen.draw.text("Очки: " + str(score), (230, 280), fontsize=40)
        return          # виходимо — персонажів не малюємо

    # звичайне малювання — тільки якщо гра йде
    fish.draw()
```

**Крок 4. Стан game_over.** Натисни **⏹️**. Додай **перед** `fish = Actor(...)`:

```python

```

```python

```

Одразу після цього рядка додай:

```python
    if game_over:
        return
```

Натисни **▶️**. Гра поки що не змінилась — але ми готові до наступного кроку.
