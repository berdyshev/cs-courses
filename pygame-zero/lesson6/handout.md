# УРОК 6. ТАЙМЕР ТА РЕСТАРТ

На цьому уроці додамо до підводної гри таймер зворотного відліку і можливість почати гру знову. Навчимося використовувати годинник гри і реагувати на натискання клавіш.

---

## ТЕОРЕТИЧНИЙ МАТЕРІАЛ

### Годинник гри — clock

`clock.schedule_interval(функція, секунди)` викликає функцію автоматично кожні N секунд:

```python
def tick():
    global timer
    timer -= 1              # зменшуємо таймер на 1 щосекунди

clock.schedule_interval(tick, 1)   # запустити tick() кожну секунду
```

Щоб зупинити відлік:

```python
clock.unschedule(tick)
```

---

### Подія натискання клавіші — on_key_down

Ми вже знаємо `keyboard.right` у `update()` — він спрацьовує **щокадру, поки клавіша утримується**. Але є інший спосіб:

```python
def on_key_down(key):
    if key == keys.R:
        # виконується один раз при натисканні R
        pass
```

`on_key_down` — **подія**: спрацьовує рівно один раз при кожному натисканні. Ідеально для рестарту.

| | `keyboard.right` у `update()` | `on_key_down` |
|---|---|---|
| Коли спрацьовує | Щокадру, поки затиснуто | Один раз при натисканні |
| Для чого | Рух | Рестарт, вибір, стрибок |

**Крок 6. Рестарт.** Додай нову функцію **перед** `pgzrun.go()`:

```python
def on_key_down(key):
    if key == keys.R and game_over:
        clock.unschedule(tick)
        init()
        clock.schedule_interval(tick, 1)
```

`init()` скидає всі змінні і позиції. `clock.unschedule()` зупиняє старий відлік, `clock.schedule_interval()` запускає новий.

Натисни **▶️**. Дочекайся кінця гри (GAME OVER або ПЕРЕМОГА!), натисни **R** — гра починається спочатку!
