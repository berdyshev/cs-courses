# УРОК 4. ДОМАШНЄ ЗАВДАННЯ

Створи гру, де гравець (керований стрілками) **уникає врагів**. Очки лічаться за кількість ворогів, які пройшли біля гравця без зіткнення.

**Завдання:**

1. Вибери спрайт для гравця (bird1–bird7, sship5 або інший)
2. Вибери спрайт для ворога (sea1–sea16, things17, things18)
3. Помісти гравця посередині екрану, керуй його **стрілками**: вліво, вправо, вгору, вниз
4. Додай **мінімум 2 ворогів**, які рухаються зліва направо (або справа наліво)
5. Коли ворог виходить з екрану — збільш лічильник на 1 (ворог "пройшов мимо")
6. Коли гравець торкається ворога — перезавантаж гру (очки на нулі) або відніми 5 очок
7. Виведи очки на екран у лівому верхньому куті

**Приклад логіки:**
```
Ворог nummer 1 входить з лівого краю...
Гравець мудро уникає...
Ворог виходить з правого краю → очки + 1
Ворог numero 2 входить одночасно...
```

**Підказка:** Можна використати дві змінні для двох ворогів:
```python
enemy1 = Actor('sea3')
enemy1.pos = (0, 200)

enemy2 = Actor('sea5')
enemy2.pos = (0, 400)
```

І для кожного перевіряй: вилетів за край → скидати позицію й лічити очко.

## ДОВІДКА

| Що | Код |
|----|-----|
| Глобальна змінна | `score = 0` (перед функціями) |
| Дозволити змінювати | `global score` (на початку функції) |
| Перевірити зіткнення | `if hero.colliderect(enemy):` |
| Вивести текст | `screen.draw.text("Очки: " + str(score), (10, 10))` |
| Перетворити число у рядок | `str(score)` |
| Керування клавіатурою | `if keyboard.right:`, `if keyboard.left:`, `if keyboard.up:`, `if keyboard.down:` |

**Доступні спрайти:**
- `bird1`, `bird2`, … `bird7` — птахи
- `sea1`, `sea2`, … `sea16` — морські істоти
- `sship5` — корабель
- `things15`, `things17`, `things18` — інші предмети

**Кольори (RGB):**

| Колір | RGB || Колір | RGB |
|-------|-----|-|-------|-----|

| Білий | `(255, 255, 255)` | | Темно-синій | `(0, 0, 50)` |
| Червоний | `(255, 0, 0)` | | Темно-зелений | `(34, 139, 34)` |

**Структура програми:**

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

score = 0

hero = Actor('bird1')
hero.pos = (400, 300)

enemy1 = Actor('sea3')
enemy1.pos = (0, 200)

def draw():
    screen.fill((0, 50, 100))
    hero.draw()
    enemy1.draw()
    screen.draw.text("Очки: " + str(score), (10, 10))

def update():
    global score
    
    # керування гравцем
    if keyboard.right:
        hero.x += 5
    if keyboard.left:
        hero.x -= 5
    if keyboard.up:
        hero.y -= 5
    if keyboard.down:
        hero.y += 5
    
    # рух ворога
    enemy1.x += 3
    
    # коли ворог вилетів за край
    if enemy1.x > 850:
        score += 1
        enemy1.x = -50
    
    # коли гравець торкнувся ворога
    if hero.colliderect(enemy1):
        score = 0

pgzrun.go()
```
